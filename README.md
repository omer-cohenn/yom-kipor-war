# מלחמת יום הכיפורים

משחק דפדפן בתלת־ממד (Three.js) על קרבות מלחמת יום הכיפורים: מעוז המזח, חילוץ לוחמי מעוז פורקן, הקרב על העיר סואץ, החווה הסינית, הצליחה, השריון ברכסים, החרמון והארמיה השלישית.

## מבנה
- `src/` — הקוד: מעטפת ה־HTML ושאר קבצי ה־JavaScript, שמחוברים לדף אחד בזמן הבנייה.
- `public/` — התמונות (`img/`), קליפי התפריט (`vid/`) והסרטונים שבתוך המשימות (`cine/`).
- `build.sh` — בונה את האתר בתיקייה `docs/` (דרך `tools/build.py`): דף קטן עם מסך הטעינה (`index.html`), קובץ הקוד של המשחק (`game.<hash>.js`, שהדף מוריד עם פס התקדמות), ולידם את `public/`. התיקייה `docs/` היא מה שהאתר מגיש.

## הרצה מקומית
```bash
bash build.sh
cd docs && python3 -m http.server 8000
```
ואז לפתוח את http://localhost:8000

## פריסה
GitHub Pages מגיש את התיקייה `docs/` מהענף `main` (Settings ← Pages ← Deploy from a branch ← main ← /docs). אחרי כל שינוי בקוד מריצים `bash build.sh` ודוחפים — האתר מתעדכן תוך דקה.
